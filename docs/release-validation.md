# 1.2.0 发布验证

日期：2026-10-29。平台：Windows x64，Windows PowerShell 5.1，Node.js 24.16.0。

## 验证范围

- 13 项运行时单元测试通过，覆盖 IPv4/IPv6 调试发现、非回环端点拒绝、空白页面识别、草稿保护与一次性安全恢复。
- 主题构建成功，生成 CSS 为 838,113 字节；主题校验无错误或警告。外观 CSS 与原版一致，本次主要变更安装交付。
- 使用真实发布包在隔离目录测试安装、重复安装、中文/空格/特殊字符路径、未知文件和日志保留、非空外部目录拒绝、损坏文件拒绝、路径越界拒绝、junction 路径拒绝、快捷方式及卸载。
- 清除测试进程的系统 Node.js PATH 后，包内 Node.js 可独立运行并完成主题校验。
- 自包含安装 EXE 支持静默安装与自定义路径，安装后可按清单卸载并清理本主题状态。
- 发布包排除原始照片、人物源 PNG、历史诊断、测试文件、运行状态和缓存，包含必要许可及第三方声明。

以上可使用 `scripts/build-release.ps1` 和 `scripts/test-release.ps1` 复现。GitHub Actions 在 Windows runner 上执行同一套验证；其结果应以仓库实际运行记录为准。

## 客户端兼容性边界

本机安装的 Codex 为 `26.1023.6123.0`。本次只读检查发现 3 个正常注入的页面（2 个对话页面、1 个独立窗口），主题和 watcher 均为 `active`，无原生主区域空白；当前已打开页面的布局检查、对比度与像素检查均通过。

这不等于完整验收最新版的所有页面。本次未为测试重启正在工作的客户端，也未切换其页面或发送内容。首页、通知、设置、终端、首页选项和悬浮侧栏仍应按维护文档分别检查；完整历史视觉验收基线为 `26.1007.2314.0`。未在另一台实体电脑、macOS、Linux 或原生 ARM64 环境验证。

安装器和启动器未做代码签名。Release 同时附带安装 EXE、便携 ZIP 和 SHA-256 校验文件；该校验文件用于检查传输完整性，不替代发行者身份验证。
