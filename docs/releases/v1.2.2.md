# G.E.M. Purple Stage 1.2.2

修复 Codex 和 ChatGPT 新对话首页在窄窗口中，四个入口被截断、出现横向和纵向滚动条的问题。

## 布局调整

- 宽内容区保留四列；窄内容区改为两列两行，四个入口完整可见。
- 紧凑卡片采用统一圆角，调整图片遮罩、字号和间距；很窄时收起说明文字，保留完整主标题。
- 较矮窗口收起装饰性副标题，并缩小入口高度。入口与输入栏保持间隔，长草稿仍优先保证编辑区可用。
- 移除重复滚动规则，使用实际网格边界进行避让，并增加布局诊断及真实浏览器回归检查。

## 下载与升级

- 安装版：下载 `gem-purple-stage-1.2.2-windows-x64-setup.exe`，选择原目录升级。
- 便携版：下载 `gem-purple-stage-1.2.2-windows-x64-portable.zip`，完整解压后运行 `GemPurpleCodex.exe`。
- 保存工作并退出旧客户端及主题 watcher，再从新版专用入口启动，同一客户端只运行一个 watcher。

两种包均包含此前的多行输入栏灰条和混合 DPI 窗口恢复修复，内置 Node.js 24.16.0，支持 Windows 10/11 x64。安装 EXE 未做代码签名；Release 附带 `SHA256SUMS.txt`。

## 验证

- 隔离夹具及当前原生首页副本分别通过 22 组浏览器布局场景与 8 项入口操作检查。两种模式、窄宽度、低高度和右面板均有覆盖；旧 CSS 会触发裁切/滚动检查。
- 13 项原有运行时测试、12 项窗口恢复策略测试、36 项安装升级和卸载检查通过。

本机原生副本来自 Codex `26.1023.6621.0`；副本渲染和点击测试不等于所有原生页面或其他实体电脑的完整验收。素材授权见 `THIRD-PARTY-NOTICES.md`。
