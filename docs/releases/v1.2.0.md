# G.E.M. Purple Stage 1.2.0

首次提供可在其他 Windows 电脑直接安装的版本，保留 v3.1 主题外观。

## 下载与安装

1. 下载 `gem-purple-stage-1.2.0-windows-x64-setup.exe`。
2. 双击安装，默认目录为 `%LOCALAPPDATA%\GemPurpleCodex`，无需管理员权限或单独安装 Node.js。
3. 保存正在进行的工作，从桌面或开始菜单的 **G.E.M. Purple Codex** 启动。

也可下载 `gem-purple-stage-1.2.0-windows-x64-portable.zip`，完整解压后运行 `GemPurpleCodex.exe`；`Install.cmd` 可将便携包安装到默认目录。请勿使用 GitHub 自动生成的 Source code ZIP 代替便携包。

## 内容与兼容性

- 包内包含通过官方 SHA-256 校验的 Node.js 24.16.0、运行程序、主题样式、素材和许可，不需要 npm 或联网下载依赖。
- 支持 Windows 10/11 x64，需已安装 Codex 桌面应用。尚未制作 macOS、Linux 或原生 ARM64 包。
- 使用系统自带的 Windows PowerShell 5.1 和 .NET Framework。安装 EXE 未做代码签名；如遇系统提示，可先核对 `SHA256SUMS.txt` 和文件来源。
- 原目录运行新版安装器即可升级，日志和运行状态保留；`Uninstall.cmd` 按安装清单移除文件，默认保留日志，带 `-PurgeState` 可一并删除本主题状态。
- 专用入口首次启动可能重启驻留后台的 Codex；不修改官方快捷方式、客户端安装目录、账号或聊天数据库。

已验证安装包校验、中文与空格路径、重复安装、文件冲突拦截、卸载保留用户文件和包内 Node.js；详细结果见 `docs/release-validation.md`。历史视觉验收基线为 Codex `26.1007.2314.0`。后续客户端可能改变界面结构，兼容性需逐页面复查。
