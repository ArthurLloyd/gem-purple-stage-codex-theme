# G.E.M. Purple Stage 1.2.3

修复 Codex 和 ChatGPT 首页卡片图片左侧大片空白、照片边缘缺少自然过渡的问题。

## 图片调整

- 用同一张照片延展柔和底图，让左侧文字区也有照片纹理。
- 右侧清晰照片保持原始比例，按当前卡片高度计算宽度；渐变从照片自己的左边缘开始，避免竖直接缝。
- 保留 1.2.2 的两列两行布局，并补充 1215 像素截图宽度和图片像素检查。

## 下载与升级

- 安装版：下载 `gem-purple-stage-1.2.3-windows-x64-setup.exe`，选择原安装目录升级。
- 便携版：下载 `gem-purple-stage-1.2.3-windows-x64-portable.zip`，完整解压后运行 `GemPurpleCodex.exe`。
- 保存工作，退出旧客户端及主题 watcher 后，从新版专用入口启动。同一客户端只保留一个 watcher。

两种包均包含此前修复，内置 Node.js 24.16.0，支持 Windows 10/11 x64。安装 EXE 未做代码签名，Release 附带 `SHA256SUMS.txt`。

## 验证

- 隔离夹具和原生首页副本各通过 24 组布局场景、8 项入口操作及 24 项图片像素检查；旧样式会触发图片纹理/接缝回归。
- 像素检查覆盖左侧照片纹理、照片边缘色阶和文字对比度，并人工查看两种入口模式及不同卡宽的渲染效果。
- 13 项运行时测试、12 项窗口恢复策略测试和 36 项打包安装升级与卸载检查通过。

原生首页副本来自本机 Codex `26.1023.6621.0`；副本测试不等于所有客户端页面或其他电脑的完整验收。素材授权见 `THIRD-PARTY-NOTICES.md`。
