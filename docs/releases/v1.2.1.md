# G.E.M. Purple Stage 1.2.1

修复 ChatGPT 多行输入栏底部的灰条，以及混合 DPI 双屏环境中最小化恢复后窗口被异常撑高的问题。保留 v3.1 主题外观。

## 本次修复

- 多行输入栏底部按钮区域正确显示主题背景，保留单行切换动画和原生控件布局。
- 为 Windows 窗口恢复增加兼容处理：同屏、同 DPI 恢复时纠正异常增大，跨屏、最大化和手动调整窗口时不干预。helper 随主题 watcher 启停，不修改客户端安装文件或系统缩放。
- 增加输入栏布局诊断、12 项窗口恢复策略测试，以及发布包内 helper 的编译检查。

## 下载与升级

1. 安装版：下载 `gem-purple-stage-1.2.1-windows-x64-setup.exe`，选择原安装目录即可升级。
2. 便携版：下载 `gem-purple-stage-1.2.1-windows-x64-portable.zip`，完整解压到新目录后运行 `GemPurpleCodex.exe`。已有便携副本可用安装程序选择旧目录升级。
3. 保存工作并退出旧的 Codex/主题 watcher，再从新版的 **G.E.M. Purple Codex** 入口启动；同一客户端只保留一个 watcher。

两种包均内置经过固定 SHA-256 校验的 Node.js 24.16.0，支持 Windows 10/11 x64，需已安装 Codex。使用 Windows 自带的 PowerShell 5.1 和 .NET Framework，无需额外安装依赖。

Release 附带 `SHA256SUMS.txt`。安装 EXE 未做代码签名，可先核对下载文件的 SHA-256。GitHub 自动生成的 Source code ZIP 供开发使用，不能代替便携包。

## 验证

- 13 项运行时测试、12 项窗口恢复策略测试，以及 36 项打包安装、升级、完整性和卸载检查通过。
- 原生输入组件隔离副本覆盖 32 组渲染场景，包括宽窄窗口、长输入和展开状态。

验证不等于所有客户端页面或其他实体电脑均已验收；客户端更新后仍需检查兼容性。照片和衍生素材的授权说明见仓库 `THIRD-PARTY-NOTICES.md`。
